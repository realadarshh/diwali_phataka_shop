PHOOLJHADI — DIWALI SHOP FRONTEND

Open index.html in a browser to preview the storefront. The site is built with plain HTML, CSS, and JavaScript (the browser language is JavaScript, not Java).

Included: responsive Diwali storefront, ten sample cracker products, product sorting, interactive cart with quantity controls, delivery/takeaway choice, and a product-specific light-up animation on add-to-cart.

This is a front-end demo. To make it a live Shopify store, connect the product cards and checkout to a Shopify store using a Shopify theme or Storefront API, then replace the sample products and prices with the store's actual catalog. The checkout button currently demonstrates fulfillment selection and does not take payment or place an order.

Use fireworks only where legal and follow the safety instructions supplied with each product.
